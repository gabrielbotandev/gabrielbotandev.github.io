# Meu Portfólio

Bem-vindo ao repositório do meu portfólio! Este repositório contém o código-fonte do meu site pessoal, desenvolvido utilizando HTML, CSS e JavaScript. Aqui você pode encontrar os detalhes sobre os projetos que estou desenvolvendo e outras informações sobre mim.

## 🚀 Visite meu portfólio

Para ver o site ao vivo, [clique aqui para visitar meu portfólio](https://gabrielbotandev.github.io).

## 📂 Estrutura do Repositório

O repositório está organizado da seguinte forma:

- `index.html`: A página principal do portfólio.
- `css/`: Contém os arquivos de estilo CSS.
- `js/`: Contém os arquivos JavaScript para interatividade.
- `assets/`: Contém imagens e outros recursos utilizados no site.

## 💻 Como Rodar o Projeto Localmente
